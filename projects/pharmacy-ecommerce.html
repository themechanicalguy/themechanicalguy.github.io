B2B Pharmacy E-commerce

At Tata Consultancy Services, frontend on a MERN B2B pharmacy storefront — React and JavaScript as the core, with enough Node.js to ship features end to end. The standout: EOF, an employee perks catalogue I owned through delivery.

Overview

The product was a B2B pharmacy e-commerce app on the MERN stack. I spent most of my time on the React frontend — interfaces, API wiring, and delivery — and picked up enough Node.js to move a feature across the stack when needed.

In the last six months I owned EOF (Employee of the Firm) end to end: an exclusive perks-and-benefits surface so the client’s employees could buy products at a discount. One owner, one initiative, from build through launch.

What I Built

  • Frontend for the B2B pharmacy storefront in React and JavaScript, including API integration and maintainable UI.
  • EOF — the employee perks catalogue: discounted product access for client staff, delivered as a full initiative rather than a one-off screen.
  • Enough Node.js on the MERN backend to take EOF from ticket to live without handing the middle of the work off.

Approach

EOF was individual ownership, not a shared backlog item. I scoped, built, and shipped it ahead of schedule with no escalations. That delivery earned formal client appreciation — the signal that the feature landed cleanly, not just that it compiled.

The rest of the tenure was frontend-first MERN work: React for the product surface, JavaScript for behaviour, Node.js when a story needed more than the UI. Keep the B2B catalogue usable; keep EOF isolated enough to ship on its own clock.
